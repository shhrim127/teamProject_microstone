# LLM과 RAG를 활용한 ChatGPT 기반 학습 지원 플랫폼

본 프로젝트는 LLM(ChatGPT)과 RAG(Retrieval-Augmented Generation)를 활용하여 대학생 대상 학습 지원 플랫폼을 구축한 연구 기반 시스템이다.  
이미지 기반 학습 자료를 OCR로 텍스트화하고, 전처리 및 벡터화 과정을 거쳐 개인 맞춤형 문제를 생성하는 AI 학습 플랫폼을 구현하였다.

본 연구는 2024년 대한전자공학회 추계학술대회 논문집에 게재되었다.

---

## 1. 프로젝트 개요

기존 대학 교육 환경에서는 충분한 문제 제공 및 해설 제공에 한계가 존재한다.  
특히 대학생을 대상으로 한 AI 기반 문제 생성 및 해설 제공 시스템은 부족한 상황이었다.

본 시스템은 다음을 목표로 개발되었다.

- 학습 자료 기반 자동 문제 생성
- 해설 및 정답 제공
- 개인 맞춤형 문제 출제
- 오답노트 기능 지원
- 커뮤니티 및 스터디 그룹 기능 제공

---

## 2. 시스템 아키텍처

본 플랫폼은 다음과 같은 구조로 구성된다.

1. OCR을 통한 학습 자료 텍스트화
2. ChatGPT 기반 데이터 전처리
3. 키워드 추출 및 벡터 DB 저장
4. RAG 기반 문제 생성
5. React 기반 프론트엔드 제공

## 4. 주요 기능

### 1) OCR 기반 자료 업로드
사용자가 업로드한 PDF 또는 이미지 자료를 OCR을 통해 텍스트로 변환한다.

### 2) LLM 기반 데이터 전처리
ChatGPT를 활용하여 불필요한 데이터 제거 및 마크다운 형식으로 변환한다.

### 3) 키워드 및 목차 추출
YAKE 알고리즘을 활용하여 핵심 키워드를 추출하고, 문제 출제를 위한 주제를 생성한다.

### 4) RAG 기반 문제 생성
벡터 DB에 저장된 학습 자료를 검색하여 신뢰도 높은 문제와 해설을 생성한다.

### 5) 오답노트 기능
사용자가 생성된 문제 및 답안을 저장하고 재학습할 수 있도록 지원한다.

### 6) 커뮤니티 및 스터디 그룹
능동적 학습을 유도하기 위한 그룹 학습 기능을 제공한다.

---

## 5. 문제 해결 접근 방식

LLM의 토큰 제한 문제를 해결하기 위해:

- 전체 문서를 직접 입력하지 않고
- 키워드 및 핵심 주제만 추출
- 벡터 검색을 통해 필요한 정보만 참조

이 과정을 통해 효율적이고 정확한 문제 생성을 구현하였다.
